AEMI WEBSITE V1.0

FILES
- index.html = website
- style.css = design
- script.js = editable AEMI information + website behavior
- aemi-logo.jpg = current AEMI logo

HOW TO EDIT
1. Open script.js in a text editor.
2. Look for "AEMI EDITABLE SETTINGS" at the top.
3. Change prices, descriptions, availability, social links, contact info, etc.
4. Save.
5. Open index.html in a browser to preview.
